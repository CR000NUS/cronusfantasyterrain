Current project scope
Choose Fantasy Regions when creating a new world. Installing the mod does not switch existing worlds automatically.
Regions repeat throughout an infinite world; there is no fixed continent.
The existing guide reports no custom biome terrain, custom cave biome selection, deliberate mountain pass system or ocean coastline.
The Nether and End use vanilla generation.
The project files record Minecraft 26.3, NeoForge 26.3.0.43-beta and Java 25.
