STANDING DECISIONS (in force)

1. Border terrain is frozen (2026-10-10)
The user said: "The terrain of the border is fine now. Do NOT change it from now on until i specifically say otherwise. If you have to change it for a reason, then first tell me so before actually changing it."
This covers the border mountain shape: RegionLayout terrain, border width, region partition and terrain density outputs. Material-only changes need their own explicit authorization.

2. Border materials (2026-10-14, from the user's drawing)
- Exposed faces below Y=220: blackstone.
- Exposed faces at and above Y=220: continuous snow cap.
- No exterior stone, deepslate, tuff, ore or random patches.
- Underground: deepslate, about 4% tuff patches and deepslate ores.

3. Border features
Only custom deepslate ore placements. No dirt, gravel, granite, diorite, andesite, vegetation or other decorative features.

4. Scorched Lands naming (2026-10-12)
Ember Lands was renamed Scorched Lands in documentation only. The code/data key stays ember_lands.

PROJECT STATUS

- Eleven regions confirmed. Five are generated with vanilla placeholder pools: Frozen Wastes, Cold Meadows, Scorched Lands, Verdant Valley, Crystal Peaks. Six are planned with no design yet: Blooming Highlands, Dry Dunes, Enchanted Groves, Land of the Giants, Misty Marshes, Shadow Wilds.
- Twenty vanilla placeholder biomes (four per region) plus one custom biome, Region Border.
- Frostscar is a planned custom biome for Frozen Wastes. Ice Desert is an earlier Test World prototype, not a biome.
- Not implemented: custom biome terrain, custom cave biomes, mountain passes, oceans or coastlines. The Nether and End are vanilla.
- Targets Minecraft 26.3, NeoForge 26.3.0.43-beta, Java 25.
