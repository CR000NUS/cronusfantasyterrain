Status: Existing region theme in Fantasy Regions.

Known theme
Dry landscapes, badlands and savanna, inferred from the placeholder pool. Custom volcanic features are not specified.

Current biome pool (vanilla placeholders)
- minecraft:desert
- minecraft:badlands
- minecraft:wooded_badlands
- minecraft:savanna

Current generation
Seeded, irregular regions repeat across the infinite Overworld, approximately 3,072 blocks across. No fixed continent or compass position is assigned.
Local biome noise selects only from the region's pool. Each pool currently has four entries; the source accepts four or five.
Interiors share gentle terrain around Y=75-85. Custom biome terrain is not implemented.
Region boundaries share the existing alpine mountain belts and Jagged Peaks biome. Internal biome boundaries do not generate these belts.
RegionBiomeSource.java maps this theme to pool index 2.

Design details still missing
Final custom biome names, terrain, vegetation, structures, mobs and other region-specific features are not fully specified in the available files.
The vanilla pool is a set of placeholders, not a confirmed final fantasy biome design.

Border instruction
The user accepted the border terrain on 2026-10-10. Do not change it unless specifically instructed. If a change becomes necessary for another reason, tell the user before changing it.
